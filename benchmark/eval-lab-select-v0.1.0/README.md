# EvalLab-Select v0.1.0

Status: planned; populated by TASK-0010 after split/fingerprint freeze.

EvalLab-Select is a compact objective benchmark for calibrated rubric judging, selective escalation, and typed decision-model differential evaluation.

The release will include deterministic source manifests/rebuild instructions, split definitions, checksums, RO-Crate metadata, PROV-O lineage, SHACL shapes, and a benchmark card covering intended use, limitations, and licensing.

It is not intended to claim universal human-evaluation coverage.
