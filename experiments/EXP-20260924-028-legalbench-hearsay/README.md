# EXP-20260924-028 — LegalBench Hearsay classification

Preregistered small legal-domain classification evaluation using the official
LegalBench Hearsay task. Its source revision, task-level license, split files,
and hashes are frozen in `source-manifest.json`. The declared test split is
primary; scores remain separate from EXP-027.

No model has run. The Hearsay task page reports 95 test examples, but the
pinned machine-readable source contains 94. The experiment uses those 94 as
distributed and records the discrepancy; it does not invent or impute an
item. This single task measures classification on hearsay examples and does
not represent general legal reasoning.
