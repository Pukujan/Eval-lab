# EXP-20260920-010 — Multi-subscription judge bakeoff

This directory contains the preregistered follow-up bakeoff for the provider-blocked TASK-0010 Qwen arm. The frozen plan is in [PLAN.md](PLAN.md), and the machine-readable manifest is in [experiment.yaml](experiment.yaml).

The experiment uses the same EvalLab-Select v0.1.0 benchmark and matched deterministic final-evaluation prefix for OpenCode `opencode/grok-4.6`, `opencode/gpt-5.6-luna`, and `opencode/gpt-5.6-sol`. YOLO-Auto Qwen and local Qwen weight arms are deferred and remain explicitly separate.

No provider evaluation has been run until the plan and offline runner/validator are committed.
